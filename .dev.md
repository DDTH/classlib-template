# Test the package locally

## Step 1: Build & Copy the Package

```sh
cp Ddth.Templates.Classlib.csproj Temp.csproj
sed -i -E "s/<<VERSION>>/0.0.0/" Temp.csproj
sed -i -E "s/<<RELEASE-NOTES>>/Local Test/" Temp.csproj
dotnet pack Temp.csproj --configuration Release --output ./temp
```

## Step 2: Install the template from local

```sh
dotnet new install ./temp/Ddth.Templates.Classlib.0.0.0.nupkg
```

## Step 3: Test the installed package

```sh
rm -rf ./temp/test; mkdir -p ./temp/test
cd ./temp/test && dotnet new clt
```
